# RTL8126 → RTL8127 Driver Delta Analysis

A comprehensive breakdown of the architectural and implementation differences between Realtek's 5Gbps (RTL8126) and 10Gbps (RTL8127) Ethernet controller drivers.

---

## Summary Table: Highest-Impact Deltas

| Category | RTL8126 | RTL8127 | Impact |
|----------|---------|---------|--------|
| **PCI Device ID** | 0x8126 | 0x8127 | Hardware identity; separate driver required |
| **PHY Speed** | 5000 Mbps | 10000 Mbps | Speed scales across entire stack |
| **Fiber Mode Support** | CFG_METHOD_3 only (8251B) | CFG_METHOD_2 only (8127ATF) | Hardware-dependent; mutually exclusive |
| **ISR Version** | 2–3 (method-dependent) | 6 (uniform) | Affects interrupt handling and MSI-X |
| **TxNoClose Version** | 4–5 (method-dependent) | 6 (uniform) | Descriptor format and pointer mask changes |
| **Rx Descriptor** | RxDescV3 only | RxDescV3 + RxDescV4 | Dual format support; V4 is default |
| **MAC MCU Page Size** | 256 words | 256 words | Same (no delta) |
| **DASH Support** | None | CFG_METHOD_2 only | 8127 adds DASH out-of-band management |
| **Firmware Variants** | FIRMWARE_8126_1, _2, _3 | FIRMWARE_8127_1, _2 | Chip-specific binaries |
| **PCI Config Registers** | 0x99, 0x22C (ASPM) | 0x99, 0x254 (ASPM) | Different ASPM offset addresses |

## 1. PCI Identifiers & Chip Detection

### Device IDs
- **RTL8126**: PCI Device ID `0x8126` (file: r8126_n.c:142)
- **RTL8127**: PCI Device ID `0x8127` (file: r8127_n.c:142)

Both use `PCI_VENDOR_ID_REALTEK` (0x10EC).

### Chip Methods (mcfg)
**RTL8126** supports three configuration methods:
- `CFG_METHOD_1` – Earliest variant
- `CFG_METHOD_2` – Mid variant
- `CFG_METHOD_3` – Latest variant with fiber support

**RTL8127** supports two configuration methods:
- `CFG_METHOD_1` – Baseline variant
- `CFG_METHOD_2` – With DASH and enhanced fiber (8127ATF)

Detection occurs in `rtl8127_hw_init` (r8127_n.c:7288–7300) and `rtl8126_hw_init` (r8126_n.c:7536–7544) by comparing chip revision IDs read from MAC OCP register `0xDC00`.

## 6. Hardware Init & Exit (hw_init / hw_exit_oob)

### Hardware Init (hw_init)
Both follow identical structure:

```c
rtl8127_hw_init() {
    rtl8127_enable_aspm_clkreq_lock(tp, 0);
    rtl8127_enable_force_clkreq(tp, 0);
    // Disable UPS
    rtl8127_mac_ocp_write(tp, 0xD40A, ... & ~BIT_4);
    // MAC MCU config
    if (!tp->rtl_fw)
        rtl8127_hw_mac_mcu_config(dev);
    // PCIE error mask
    csi_tmp = rtl8127_csi_read(tp, 0x108);
    csi_tmp |= BIT_20;
    rtl8127_csi_write(tp, 0x108, csi_tmp);
    // Wakeup/power config
    rtl8127_disable_linkchg_wakeup(dev);
    rtl8127_disable_magic_packet(dev);
    rtl8127_disable_d0_speedup(tp);
    // Firmware application
    if (tp->rtl_fw && !tp->resume_not_chg_speed)
        rtl8127_apply_firmware(tp);
}
```

- RTL8127: r8127_n.c:7808–7842
- RTL8126: r8126_n.c:7422–7456

## 11. Miscellaneous Pitfalls & Edge Cases

### 1. **Fiber Mode + DASH Mutual Exclusivity**
RTL8127 detects fiber mode at CFG_METHOD_2. When enabled, DASH must coexist but EEE is disabled. No documented conflict exists, but both features should be tested together.

### 2. **EPHY Register Configuration**
RTL8127 CFG_METHOD_2 configures 24 EPHY registers (r8127_n.c:7851–7892). This is absent in CFG_METHOD_1. Porting code between methods requires ensuring EPHY init is method-aware.

### 3. **RxDesc Type Mismatch**
RTL8127 supports dual descriptor versions (V3 and V4). The hardware register `0xd8` bit `EnableRxDescV4_0` must match the descriptor type being used. Misalignment causes reception failures.

### 4. **TxNoClose Pointer Mask Version Matching**
RTL8127 uses `HwSuppTxNoCloseVer = 6`, which requires `MAX_TX_NO_CLOSE_DESC_PTR_MASK_V4`. Using V3 mask with V6 pointers results in incorrect descriptor address wrapping.

### 5. **OOB (Out-of-Band) Notification Missing**
RTL8126 lacks any DASH or OOB mechanism. RTL8127 requires explicit `rtl8127_notify_dash_oob()` calls when DASH is enabled and driver is stopping. Omitting this can leave firmware in an inconsistent state.

### 6. **ISR Downgrade Fallback**
Both drivers downgrade from their max ISR version to ISR_V1 if MSI-X vectors are insufficient (< min_irq_nvecs). This is intentional but can silently degrade performance if not monitored.

### 7. **MAC MCU Page Size Constant**
Both define `RTL8127_MAC_MCU_PAGE_SIZE = 256` and `RTL8126_MAC_MCU_PAGE_SIZE = 256` (identical). These are named per-chip for clarity and future-proofing, but are functionally equal.

### 8. **PCI ASPM Config Register Offset Drift**
RTL8126 uses 0x22C for the second ASPM offset; RTL8127 uses 0x254. Hardcoding either offset is a critical bug. Always derive from `tp->org_pci_offset_180`.

### 9. **Hardware Revision Detection**
Chip method detection reads MAC OCP 0xDC00 and shifts by 3 bits, masking to 0x07. This value is chip-specific and different between revisions. Do not assume any two methods produce the same value.

### 10. **Firmware Enable Conditional**
Both drivers support `ENABLE_USE_FIRMWARE_FILE` to load firmware from disk instead of built-in. When porting to macOS, ensure firmware files are shipped separately or built-in firmware is correctly embedded.
